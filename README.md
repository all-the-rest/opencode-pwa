# Web PWA for Opencode

Installable multi-server client for the Opencode V2 API. Client-side only, no backend.
German UI, English code and docs.

## Setup

Requires Node 20+ and pnpm 9+.

```bash
pnpm install
pnpm dev      # dev server on http://localhost:5173
pnpm build    # typecheck + production build
pnpm preview  # preview the production build
```

## Multi-Server + Basic Auth

- Servers are managed under **Einstellungen** (name, base URL, Basic Auth user/password).
- Stored in `localStorage` under key `opencode-pwa:servers`. One user per server.
- Every API call sends `Authorization: Basic base64(user:pass)` when credentials are set.
- Optional: `VITE_DEFAULT_SERVER_URL` (see `.env.example`) pre-selects the matching stored
  server on first load.
- No secrets are committed. Never put credentials in code.

## PWA Install

- Manifest and service worker are generated by `vite-plugin-pwa` (see `vite.config.ts`).
- Manifest: name "Web PWA for Opencode", icons `pwa-192x192.png`, `pwa-512x512.png`
  (placeholder 1px PNGs, see AGENTS.todo.md), `pwa-icon.svg`.
- No static `public/manifest.webmanifest` is committed: the plugin injects the manifest link
  at build time. If hosting without plugin output is ever needed, add a static manifest
  file in `public/` as fallback.
- `registerSW({ immediate: true })` in `src/main.tsx` enables auto-update.

## V2 API Endpoints Used

Via `@opencode/client` (`OpenCode.make({ baseUrl, headers })`), see `src/lib/opencode.ts`:

| Function         | Endpoint        |
| -------------- | --------------- |
| `getServerInfo`| `GET /api/info` (client: `server.info()`) |
| `listSessions` | `GET /api/session` (client: `session.list()`) |
| `listMessages` | `GET /api/session/:id/message` (client: `message.list()`) |
| `listAgents`   | `GET /api/agent` (client: `agent.list()`) |
| `listShells`   | `GET /api/shell` (client: `shell.list()`) |
| `listPtys`     | `GET /api/pty` (client: `pty.list()`) |
| `subscribeEvents` | `GET /api/event` SSE stream (client: `event.subscribe()`) |

All calls handle offline/errors gracefully (`{ data, error }` results, warning banners in UI).

## Project Structure

```
index.html
vite.config.ts          # tailwind + PWA + dev port 5173 + vitest
playwright.config.ts    # chromium + mobile (Pixel 7), webServer pnpm dev
src/
  main.tsx              # entry, SW registration, ServerProvider
  App.tsx               # routes
  index.css             # tailwind + daisyui
  components/Layout.tsx # drawer + navbar shell
  pages/
    Dashboard.tsx       # / server list + status
    ServerDetail.tsx    # /servers/:id sessions + shells + ptys
    SessionDetail.tsx   # /sessions/:id messages (read-only MVP)
    Settings.tsx        # /settings server management
  lib/opencode.ts       # API wrapper
  state/servers.tsx     # server context + localStorage
  lib/*.test.ts(x)      # vitest unit tests
tests/e2e/smoke.spec.ts # playwright smoke (@smoke)
features/               # architecture / API contract / userscripts notes
```
